# Company Logo Setup Instructions

## Required Logo Images

You need to download transparent PNG logo images for the following companies and save them in the `images` folder:

### 1. **Verizon**
- **Filename:** `verizon-logo.png`
- **Download from:** [Verizon Brand Center](https://www.verizon.com/about/sites/default/files/Verizon_Logo_BLK_RGB.png) or search "Verizon logo transparent PNG"
- **Recommended size:** 300x100px or similar aspect ratio

### 2. **Liberty Global**
- **Filename:** `liberty-global-logo.png`
- **Download from:** Search "Liberty Global logo transparent PNG"
- **Recommended size:** 300x100px or similar aspect ratio

### 3. **Viacom**
- **Filename:** `viacom-logo.png`
- **Download from:** Search "Viacom logo transparent PNG" or "Paramount Global logo PNG"
- **Note:** Viacom is now Paramount Global, you can use either logo
- **Recommended size:** 300x100px or similar aspect ratio

### 4. **AT&T**
- **Filename:** `att-logo.png`
- **Download from:** Search "AT&T logo transparent PNG"
- **Recommended size:** 300x100px or similar aspect ratio

### 5. **Comcast**
- **Filename:** `comcast-logo.png`
- **Download from:** Search "Comcast logo transparent PNG"
- **Recommended size:** 300x100px or similar aspect ratio

## Quick Download Sources

### Option 1: Official Brand Sites
- Visit each company's official "Press" or "Brand" page for high-quality logos

### Option 2: Logo Download Sites
- [Brandfetch](https://brandfetch.com/) - Type company name to download logos
- [Seeklogo](https://seeklogo.com/) - Free logo database
- [Worldvectorlogo](https://worldvectorlogo.com/) - Vector logos in PNG format

### Option 3: Google Image Search
1. Search: `[Company Name] logo transparent PNG`
2. Click "Tools" → "Color" → "Transparent"
3. Look for high-resolution images (at least 300px width)

## Styling Notes

The logos will automatically:
- ✅ Display in a 3-column grid (2 rows)
- ✅ Convert to white/monochrome to match your dark theme
- ✅ Scale to 50px height while maintaining aspect ratio
- ✅ Brighten on hover with scale effect
- ✅ Look professional and consistent

## Tips for Best Results

1. **Prefer transparent backgrounds** (PNG format)
2. **Higher resolution is better** (300px width minimum)
3. **Official brand logos** look most professional
4. **Horizontal logos** work best in this layout
5. If a logo has both horizontal and vertical versions, choose **horizontal**

## Testing

After downloading the logos:
1. Place all 5 PNG files in the `images` folder
2. Open `index-optimized.html` or `index (1).html` in your browser
3. Check the "Major Telcos & Media Companies" section
4. Logos should appear in white/monochrome on hover

## Troubleshooting

**If logos don't appear:**
- Check file names match exactly (case-sensitive)
- Verify files are in PNG format
- Ensure files are in the `images` folder
- Clear browser cache and refresh

**If logos look distorted:**
- Try different logo versions (horizontal format works best)
- Logos automatically scale to 50px height maintaining aspect ratio
